# Módulo 3: Taller de Fotografía

## Descripción del Proyecto

Informe técnico del Módulo 3 de *Técnicas y Herramientas Modernas II* (Ingeniería Industrial, FI – UNCuyo, 2026).

Aplicamos técnicas de fotografía forense para registrar y analizar la falla de una barra de acero usada como palanca. A partir de las imágenes se determinó el mecanismo de rotura (fractura frágil a flexión) y se analizaron los parámetros técnicos de las fotos como evidencia documental.

## Contenido

- Identificación del objeto y mecanismo de rotura
- Relación con la ciencia de los materiales
- Análisis de metadatos EXIF
- Análisis técnico del registro fotográfico
